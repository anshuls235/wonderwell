# Wonderwell: Anshul's Big Idea

An original side-scrolling platform adventure made with Godot 4.7.

**Play:** https://anshuls235.github.io/wonderwell/

- Keyboard: ← → / A D move · Space jump (hold to jump higher, glide) · Shift run · C Pip's Pulse · ↓ in the air ground-pound · V Spark Dash · Esc pause
- Controller supported. On phones and tablets, on-screen touch controls appear automatically.
- On a phone, use "Add to Home Screen" to install it as an app (landscape, full screen).
- Progress saves in your browser.

This repository contains only the published web build.
